# Experiment 8 - Develop RESTful APIs using Flask

## Objective
To develop RESTful CRUD APIs using Python Flask framework.

## Technologies Used
- Python
- Flask
- Postman
- Render (Deployment)

## API Endpoints

1. POST /students - Add student
2. GET /students - Get all students
3. GET /students/<id> - Get student by ID
4. PUT /students/<id> - Update student
5. DELETE /students/<id> - Delete student

## Storage
Student data is stored in-memory using a Python list.

## Testing
APIs were tested using Postman.

## Deployment
Application deployed on Render platform.
